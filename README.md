# TT-sensei CODE QUEST

小学校1〜6年生向けビジュアルプログラミング学習教材「考えて、動かして、創り出そう。」

ロボットに命令ブロックを組み合わせてミッションをクリアしながら、順次処理の考え方を学びます。

## あそびかた

- トップ画面でミッションとパートナー（ナビアン）を選ぶ
- 命令ブロック（まえに すすむ／うしろに さがる／みぎを むく／ひだりを むく）をタップで並べてプログラムを作る
- 「じっこう」でパートナーが動き、フィールド上の敵ナビアンを全部倒す（＋スター回収）でクリア。フィールドにはSTEPごとにファンタジー背景を表示
- クリアでパートナーが育ち、3段階に進化する（ぷるんスライム／さくらスノーパフ／もふウルフから選択）

## 内容

- Phase 1：ミッション35問（STEP1 命令を知る／STEP2 組み合わせ・スターと順番／STEP3 振り返り・デバッグ／STEP4 チャレンジ）
- Phase 2：STEP5 くりかえし 10問（36〜45）＋STEP6 じょうけん 10問（46〜55）。「くりかえし」ブロック（回数1〜9・入れ子対応）は36番以降、「もし まえが かべ なら」ブロックは46番以降のミッションでのみパレットに出る。クリア時に使ったプログラムと振り返りは「学びのきろく」画面で見返せる
- 敵ナビアン：全55問に1〜3体を配置（最後の1体は旧ゴール位置、追加分は全解法が必ず通るマスにのみ配置）。倒すと名前つきで撃破表示
- Phase 3：自由制作モード。盤面5×5〜8×8、背景10種、スタート（向き指定）・敵（最大6体）・岩・スターをタップ配置して、プログラムで遊べる。作品は名前つきで端末内に12件まで保存でき、プログラムも一緒に保存される
- デバッグ問題（最初から入っているプログラムを直す形式）を含む
- 外部API・外部ライブラリ不使用の単一HTML。記録はブラウザの localStorage に保存
- パートナーの画像は NAVI CHARACTER（https://tt-sensei.github.io/navi-character-/）の公開アセットを参照
